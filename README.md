# Organizador de tareas con 3 bots

Proyecto mínimo en Python para practicar un flujo en cadena:

- **Bot 1** limpia la lista de tareas.
- **Bot 2** clasifica por prioridad básica.
- **Bot 3** redacta el resumen final.

## Cómo usarlo

1. Edita `input.txt` con tus tareas.
2. Ejecuta:
   ```bash
   python main.py
   ```
3. Revisa `output.txt`.
